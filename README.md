# matrlab
Задаие для л/р 1: Написать программу на языке C/C++ для перемножения двух квадратных матриц.
Исходные данные: файл(ы) содержащие значения исходных матриц.
Выходные данные: файл со значениями результирующей матрицы, время выполнения, объем задачи.
Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например на Matlab/Python).

Ниже приведена таблица, где написаны размер матрицы, время, затраченное на умножение матриц и количество операций.

В ходе выполнения лабораторной работы №1 была разработана программа на языке C++ для перемножения двух квадратных матриц. Программа читает исходные матрицы из файлов matrix_A.txt и matrix_B.txt, выполняет умножение, записывает результат в файл result_matrix.txt, измеряет время выполнения с помощью библиотеки chrono и выводит размер матрицы и количество выполненных операций. Для проведения экспериментов был написан код на Python, который генерирует матрицы размером 100, 200, 400, 800, 1200 и 1600 элементов и сохраняет их в файлы с соответствующими названиями. Затем программа запускалась для каждого размера, и были получены следующие результаты времени выполнения: для матрицы 4x4 время составило 0.0000128 секунды, для 100x100 – 0.0197855 секунды, для 200x200 – 0.197638 секунды, для 400x400 – 1.1758 секунды, для 800x800 – 10.1821 секунды, для 1200x1200 – 43.6735 секунды и для 1600x1600 – 95.4251 секунды. Для верификации результатов был создан код на Python, который выполняет умножение матриц и сравнивает с результатом C++ программы(в файле приведен пример для матрицы 1600x1600). Проверка показала, что результаты совпадают с максимальной разницей порядка 5e-4, что допустимо при использовании чисел с плавающей точкой. На основе полученных данных был построен график зависимости времени от размера матрицы, из графика видно, что производительность снижается с ростом размерности входных данных.
